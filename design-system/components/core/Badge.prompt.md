Small uppercase status pill — milestone states, "LIVE" indicators, inline tags.

```jsx
<Badge tone="unlocked" dot>Unlocked</Badge>
<Badge tone="locked">Locked</Badge>
<Badge tone="live">Live from Stripe</Badge>
<Badge tone="cash">Premium</Badge>
```

Tones: `unlocked` (green), `locked` (muted), `live` (green + pulsing dot, auto), `cash` (gold), `neutral`. Set `dot` to force the leading dot on any tone.
